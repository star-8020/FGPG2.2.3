# FGPG2.2.0 — Shaper-Cutter Root Fillet Algorithm: Technical Whitepaper & Implementation Specification

---

## Abstract

This document presents the theoretical background, mathematical formulation, and software integration plan for incorporating a **Shaper-Cutter Root Fillet Algorithm** into the Fine Gear Profile Generator (FGPG2.2.0). The proposed method replaces the rack-based trochoid approximation with a physically accurate **gear–gear conjugate generation model**, thereby achieving improved tooth-root strength and geometric fidelity.

The approach is grounded in the algorithm proposed by **George Lian (2006)**, which defines the fillet form generated by a shaper cutter with involute sides and an elliptical tip. The presented method solves the non-linear system governing cutter–gear meshing using Newton–Raphson iteration and is validated against AGMA 918-A93 examples.

---

## 1. Introduction

In traditional gear-profile generation, the root fillet (trochoid) is derived under the assumption that a **rack tool** generates the involute tooth form. This simplification introduces a minor geometric discrepancy between the analytical model and the actual shaped gear, especially at the transition between the involute and the fillet. 

However, when gears are **shaped** (i.e., generated by a shaper cutter with involute flanks), the contact kinematics differ fundamentally. The tooth root fillet is produced by the tip of the cutter, not by a rack-type motion. This results in a more natural trochoidal transition, better stress distribution, and enhanced bending strength.

By implementing the shaper-cutter algorithm, FGPG2.2.0 will support:
- True conjugate gear–gear generation.
- Direct control of protuberance and tool-tip radius.
- Accurate Start of Involute (SOI) prediction.
- Finite Element Analysis (FEA)-ready fillet geometries.

## 2. Theoretical Background

### 2.1 Generating Principle
A shaper cutter can be visualized as a generating gear meshing with the work gear under zero backlash. The locus of the cutter’s tip defines the trochoid of the gear root.

### 2.2 Comparison: Rack vs. Shaper Models
| Property | Rack-Generated Fillet | Shaper-Generated Fillet |
|-----------|----------------------|--------------------------|
| Generating Element | Linear rack | Rotating gear (shaper) |
| Contact Geometry | Linear | Conjugate circular motion |
| Fillet Realism | Approximation | Physically accurate |
| Strength | Standard | Enhanced (due to smoother curvature) |
| Undercut Control | Indirect | Direct via δ₀ and ρ₀ parameters |

## 3. Mathematical Formulation

### 3.1 Tool and Gear Parameters

| Symbol | Description | Unit |
|---------|--------------|------|
| Pnd₀ | Normal diametral pitch of tool | in⁻¹ |
| n₀ | Number of cutter teeth | — |
| φₙ₀ | Reference normal pressure angle | ° |
| ψ₀ | Reference helix angle | ° |
| sₙ₀ | Reference normal circular thickness | in |
| dₐ₀ | Outside diameter of cutter | in |
| ρ₀ | Tool tip radius | in |
| δ₀ | Protuberance | in |

### 3.2 Geometric Foundations
The cutter and gear geometry are established from equations (1–14) in Lian (2006):

\[
rb₀ = r₀ \cos φ₀, \quad p_{nb₀} = \frac{π \cos φ_{n₀}}{Pnd₀}, \quad s_{b₀} = 2r_{b₀}(φ₀ + inv(φ₀))
\]

### 3.3 Cutter Tip Determination
The cutter tip’s geometric configuration is defined by four unknowns:
\[
X = [r_{S₀}, λ_{S₀}, θ_{Pn₀}, θ_{En₀}]
\]

Subject to the following non-linear constraints:
1. Profile tangent point alignment.
2. Circular thickness consistency (ζₚ₀ relation).
3. End tangent on cutter OD.
4. Tangent-angle equality at E₀.

The system \( F(X) = 0 \) is solved via the **Newton–Raphson method**:
\[
J·δX = -F(X)
\]
where \( J = ∂f_i/∂x_j \) is the Jacobian approximated by finite differences.

Convergence criterion:
\[
||F(X)|| < 10^{-10}, \quad iter_{max} = 30
\]

### 3.4 Trochoid Generation
Once the cutter geometry is fixed, the trochoid is generated by tracing the cutter-tip points (Zone 2). For each point X₀:
1. Compute its normal slope \( m_{X₀} = tan(θ_{Xn₀})/cos(ψ₀) \).
2. Determine intersection with generating pitch circle (G₀).
3. Rotate cutter by \(-ξ₀\); gear rotates by \(±ξ = ξ₀·(n₀/n)\).
4. Transform coordinates to the gear reference frame:
\[
T_{X₀} = M(-ξ)(X₀' - O_G)
\]
The resulting locus forms the **root trochoid**.

### 3.5 Start of Involute (SOI)
The SOI occurs when the trochoid intersects the involute profile. Let \( ε_{tro} \) and \( ε_{inv} \) denote the polar angles of the trochoid and involute at equal radii:
\[
ε_{tro} = ε_{inv}
\]
The corresponding diameter defines the SOI — crucial for determining finishing stock and avoiding undercut.

## 4. Software Architecture

### 4.1 Integration Overview
```
/fgpg/core/
  ├── geometry.py          # Eq.(1)-(14) base geometry calculations
  ├── newton.py            # Generic multi-variable Newton solver
  ├── shaper_fillet.py     # Shaper-cutter trochoid implementation
  ├── involute.py          # Involute coordinate utilities
  └── dxf_exporter.py      # DXF generation
```

### 4.2 Configuration Parameter
```yaml
root_fillet_method: "rack_trochoid" | "shaper_trochoid"
```
This allows users to switch between the conventional rack-based and the new shaper-based models.

### 4.3 Function Specification
```python
def compute_shaper_root_fillet(gear, tool, opts):
    """
    gear: {Pnd, n, φn, ψ, sn, μs, ...}
    tool: {Pnd0, n0, φn0, ψ0, sn0, da0, ρ0, δ0}
    opts: {tol=1e-10, max_iter=30, ds=0.001}

    Returns:
        fillet_points: [(x, y), ...]
        soi_diameter: float
        debug: dict (iteration history)
    """
```

Integration hook:
```python
if cfg.root_fillet_method == "shaper_trochoid":
    fillet = compute_shaper_root_fillet(...)
else:
    fillet = compute_rack_trochoid(...)
```

## 5. Verification and Results

Validation was performed using *AGMA 918-A93 Example 3.1.5*.

| Tool Type | Teeth Count | Max Fillet Deviation vs Hob (in) | SOI Difference (in) |
|------------|--------------|----------------------------------|--------------------|
| 100T Shaper | 100 | 0.001901 | 0.010209 |
| 1000T Shaper | 1000 | 0.000111 | 0.001158 |
| 10000T Shaper | 10000 | 0.000011 | 0.000117 |

As the cutter teeth increase, the generated trochoid converges toward the hobbed (rack-limit) geometry, validating the correctness of the shaper-based model.

## 6. Discussion

### 6.1 Strength Benefits
- The root curvature is continuous and physically constrained by the tool-tip path, producing a stronger fillet.
- The protuberance δ₀ allows fine-tuning of stock for grinding and avoids undercut.
- The conjugate gear–gear motion eliminates artificial spline artifacts.

### 6.2 Numerical Stability
- Newton iteration converges rapidly (<10 iterations) under standard parameters.
- Recommended initial values: 
  \( r_{S₀} ≈ d_{a₀}/2 - ρ₀, θ_{Pn₀} ≈ -φ_{n₀}, θ_{En₀} ≈ -1.48 rad \).
- Step size ΔX = (0.01, 0.01, 0.01, 0.01).

### 6.3 Engineering Implications
This implementation allows FGPG2.2.0 to simulate realistic manufacturing geometry directly — making it suitable for advanced CAE applications, optimization of cutter design, and precise control of finishing stock.
